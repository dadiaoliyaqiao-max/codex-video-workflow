# Codex 视频剪辑工作流

适用于在 Windows 上用 Codex 组织短视频制作。仓库包含项目规则、阶段控制器、模板、常规 FFmpeg 渲染与调色辅助脚本，以及按步骤说明各工具实际作用的文档。它是可复用的**流程和源码包**，不含原片、已完成视频、真人封面、账号、密钥、转写模型或第三方程序安装包。

## 从哪里开始

1. 第一次使用：阅读[同事下载与使用](同事下载与使用.md)。公开仓库可直接下载，无需 GitHub 账号；配置本机环境后运行 `工作流工具.cmd doctor`。
2. 开始一个视频：阅读[开始使用](开始使用.md)，将素材放进独立的 `剪辑项目/项目名/素材/`，让 Codex 读取根目录 `AGENTS.md` 和 `workflow-kit/codex-video-workflow/SKILL.md`。
3. 了解每一步：阅读[完整工作流](完整工作流.md)和[逐步工具调用与开源项目](逐步工具调用与开源项目.md)。
4. 已装过旧包：按[从旧包更新](从旧包更新.md)迁移，保留旧项目与本机配置。

## 核心约束

- 每片独立管理；原始素材不修改，所有派生文件落本片 `edit/`。
- 默认三个真人确认点：剪辑思路、正式分镜、完整预览与实际封面。用户明确要求免审交付时，仅在该片范围内记录授权并进行技术检查。
- 真实转写和词时间是字幕、重点字及音效同步的依据；无法转写时不编造时间轴。
- FFmpeg负责常规剪辑、调色、字幕和混音；有参考视频时按需用 Hypit；复杂动效才按需选择 HyperFrames 或 Remotion。第三方工具未随仓库提供。
- 仓库中的系列封面图是无真人照片的结构示意。每条片的标题、人物、地点、曲目和具体调色值均由当期需求确定。

## 目录

| 路径 | 作用 |
| --- | --- |
| `AGENTS.md` | 项目总规则和确认边界 |
| `workflow-kit/codex-video-workflow/SKILL.md` | Codex实际剪辑入口 |
| `workflow-kit/` | 流程控制、媒体索引、参考分析、封面检查和测试 |
| `video-use/helpers/` | FFmpeg渲染、调色辅助代码 |
| `templates/` | 每片brief、分镜、词时间、交付记录等模板 |
| `series-assets/` | 不含真人照片的封面布局示意 |
| `剪辑项目/` | 各片独立工作目录；实际项目不提交到仓库 |

## 适用范围与验证

仓库入口是 Windows `工作流工具.cmd`。最低环境为 Node.js、Python 3.10+、Pillow、带 `libass` 和 `libx264` 的 FFmpeg/FFprobe；Hypit、转写及复杂动效环境按需配置。[环境与命令](环境与命令.md)列出具体入口和限制。[validation.json](validation.json)记录此前本机合成测试的范围，不代表新电脑、真实影片或第三方服务已经通过验收。

`video-use` 随附代码的许可见 [video-use/LICENSE](video-use/LICENSE)；其他外部项目的安装、许可和素材授权需分别确认。更多来源见[来源与边界](来源与边界.md)。
