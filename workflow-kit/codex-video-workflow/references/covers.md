# 系列封面

## 与视频的顺序

思路中确定封面方向、系列固定项、当期可变项、准确标题和交付尺寸；分镜确认后制作。
首次系列先完成一张，和完整视频预览一起呈现，由用户确认样式。后续沿用已确认的系列规则，
替换本期画面和文案。终稿同时交付视频和已审 PNG/JPG，不增加固定的第四个审批点。

## 输入与风格

参考图放在项目 `封面参考/`，也可使用用户本次明确给出的文件。
从参考图提取配色、版式、标题层级、字体风格、主角或产品位置、角标和留白；
不要猜测无法确认的精确字体、品牌字或小字。
固定项写入本项目 `edit/cover/style.json` 或封面说明；标题、期数与主体作为当期变量。
复用的是用户已确认的系列样式，不自动混入无关项目的素材或私有信息。

准确文案、尺寸与系列标识记录在 `brief.cover`。参考图、Logo等纳入 `reference_files`；
相对路径均从 `edit/` 解析。不要默认编造标题、Logo或真实人物/产品。
用户未给封面参考时可根据本片提出封面方向，在思路阶段落实。

## 工具

- 从视频取真实关键画面：FFmpeg，记录源文件与时间码。
- 需要参考风格生成画面、修图、抠图或合成时：读取 imagegen Skill，默认用内置图像生成/编辑工具；先查看本地输入图。没有必需的参考图时先取得该图，不生成无关替代品。
- 精确标题、Logo与已有矢量版式：在可编辑的 SVG/HTML 等原生设计中准确排版，使用已确认文字与原始 Logo，最终输出实际 PNG/JPG。不要把生成图中的错字当成最终文字，不用占位矢量图冒充用户要求的照片。
- 保存封面源文件、实际使用的参考与必要生成记录；项目引用的图必须复制到本项目，不能仅留在生成工具默认目录。

保持原人物和产品的重要特征，检查文字逐字准确、Logo、裁切安全区、系列一致性与小屏可读性。
不要仅根据 AI 返回成功或文件能打开就称设计已通过用户确认。

## 当前封面清单

制作完成后写入 `edit/cover/cover_manifest.json`，不要预填审批：

```json
{
  "version": 1,
  "title": "经本次确定的标题",
  "files": [{"file": "cover/cover_v001.png", "role": "primary"}],
  "source_files": ["../封面参考/reference.png"]
}
```

相对路径从 `edit/` 解析；清单只列本次交给用户确认和最终交付的图片，不把弃用草稿列成已审交付。
预览确认同时绑定视频、封面清单、实际图片与来源指纹。封面或来源变更后重新确认当前组合；
没有影响视频时不要求无故重渲染。方向和参考变化影响思路时更新 brief，再落实上游确认。
